# 变更日志

本文件用于记录项目中所有值得关注的代码与功能变更。

格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，
正式发版时可按 [Semantic Versioning](https://semver.org/lang/zh-CN/) 维护版本号。

## [未发布]

### 新增

- 新增 Coze 工作流数据源适配器，并接入统一数据源管理器。
- 新增基于 Coze 的重点股票同步、全市场补库、能力检查和适配器验证脚本。
- 新增系统状态后端与前端页面，用于展示基础服务、数据源、数据集与功能接口状态。
- 新增数据库完整性、覆盖率和数据源路由可见性诊断能力。
- 新增监听通知 dry-run 能力及相关验证/测试覆盖。
- 新增提交规范文档，并约定后续提交前需要更新本变更日志。

### 变更

- 重构 `stock_daily` 与 `daily_basic` 同步流程，支持更安全的增量同步、重点股票同步与多源回退。
- 调整统一数据源默认调度规则，使单股、实时、财务类请求优先走更合适的可用数据源。
- 重构系统状态页，改为概览加分区加载、缓存和接口矩阵展示。
- 调整订阅、监听与股票详情相关链路，使其与当前监听架构保持一致。

### 修复

- 修复因本地 `stock_basic` 缺失导致的股票搜索异常。
- 修复多处 Tushare 集成问题，包括错误地址、健康检查与权限不足时的回退逻辑。
- 修复 AKShare 与 BaoStock 在最近交易日推断上的兼容问题。
- 修复监听模块在策略参数、快照处理与通知链路上的兼容问题。
- 修复前端构建阻塞项以及系统状态页若干展示问题。
