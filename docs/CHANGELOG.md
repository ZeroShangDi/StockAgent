# 变更日志

本文件用于记录项目中所有值得关注的代码与功能变更。

格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，
正式发版时可按 [Semantic Versioning](https://semver.org/lang/zh-CN/) 维护版本号。

## [未发布]

### 新增

- 新增 DataSync 保守运行档、市场晴雨表同步任务和服务器运行保护配置，默认只注册核心行情与市场统计链路。
- 新增 Strategy V2 后台运行并发限制配置，默认同一 Web 进程只执行 1 个策略任务运行，避免全市场任务叠加。

### 变更

- 收敛 DataSync 默认执行行为，禁止启动时全任务同步、限制任务并发和采集并发，并阻止首次运行自动全历史回补，降低服务器 CPU 与内存峰值。
- 优化 Mongo 聚合、DataSync 失败重试和板块分析查询路径，减少无界结果集加载，并下调服务器示例中的 Mongo/Redis/LLM 并发默认值。
- 收敛推理节点、监听大股票列表、市场晴雨表回补、热点新闻和事件聚类的默认并发与批次，降低 4c8g 服务器运行尖峰。

- 修复任务列表关键词展示不准确的问题，将任务列表中的关键词调整为策略名。
- 修复任务详情打开为空页面的问题，并优化任务页面表格布局、状态展示与详情入口。
