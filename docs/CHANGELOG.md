# 变更日志

本文件用于记录项目中所有值得关注的代码与功能变更。

格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，
正式发版时可按 [Semantic Versioning](https://semver.org/lang/zh-CN/) 维护版本号。

## [未发布]

### 新增

- 新增分钟异动监听策略，支持按最近 N 分钟涨跌幅超过阈值时触发短线预警。
- 新增持仓股页面，支持按交割单分组查看当前股票持仓、持仓成本、最新估值、浮盈亏和批量操作。
- 新增持仓盈亏阈值与盘中持仓盈亏变化两种监听策略，可直接基于交割单持仓分组做盘中预警。
- 新增固定止损与移动止损两种监听策略，支持按单只股票保存止损基准并在节点重启后继续生效。
- 新增 Coze 全量插件状态探测接口，可单独重复刷新 20 个扣子股票插件的可用状态、耗时、返回结构和项目接入情况。
- 新增交割单复盘第一版，支持分组管理、CSV 去重导入、逐笔复盘备注、基础统计和交易 K 线联动。
- 新增交割单沉浸式复盘页，支持 K 线、同股交易列表、复盘表单同屏协作，以及上一条、下一条的连续复盘流程。

### 变更

- 调整侧边菜单分组与顺序，拆分为“新增与改造”和“原项目页面”两组，并按实际使用链路重排高频入口。
- 调整策略监听页面，将“监听频率”和“提醒频率”提取到独立的监听基础配置区块，为后续策略中心解耦做前置整理。
- 调整 `5日线低吸`、`涨跌停打开` 等策略的参数定义，补齐提醒频率、监控方向等基础参数并统一中文展示。
- 调整交割单导入后的处理流程，新增持仓快照自动重算与股票持仓默认过滤视图。
- 调整监听节点的监控股票收集逻辑，支持从交割单持仓快照自动扩展持仓分组的监控标的。
- 调整策略参数配置界面，支持为持仓监听策略直接选择交割单分组与波动方向。
- 调整策略监听配置界面，固定止损、移动止损与撑压线统一支持按股票单独配置和批量加入后的提示说明。
- 调整实时行情默认回退顺序，在 Coze 返回空时优先切到 Tushare，避免少量股票实时查询被 AKShare 全市场接口拖慢。
- 调整统一数据源优先级，使 Coze 优先承担单股实时、单股日线与财务类请求，免费源作为主要回退，Tushare 退居最后兜底。
- 调整系统状态页数据源区块，新增 Coze 插件状态明细与单独刷新入口，便于反复观察偶发失败和持续失败。
- 调整通用 K 线组件，支持按交易记录打买卖点标记，并统一按交易日升序绘制数据。
- 调整交割单复盘数据结构，将成败原因统一为“单一结果判定 + 原因标签”模型，并改为由后端按分组全量聚合统计。
- 调整交割单复盘列表页，补充分页、统计说明与进入沉浸式复盘的入口。
- 调整交割单 K 线复盘体验，支持同股切换时重新聚焦当前交易位置、当前记录高亮与未保存离开提醒。

### 修复

- 修复自动流转规则中的来源股池只参与流转、不参与实际监听范围的问题，来源股池内股票现在会自动并入 listener 的有效监控集合。
- 修复固定止损等策略在达到触发条件后仍按分钟重复提醒的问题，统一补充每日一次、提醒后关闭和不限次数三种提醒频率行为。
- 修复提醒状态只写入数据库但未同步回 listener 进程内存配置的问题，避免同一运行周期内重复触发。
- 修复交割单导入去重过粗导致“同日同价但资金余额不同”的独立成交被误判为重复，从而影响持仓快照的问题。
- 修复 Tushare 实时行情返回短代码 key 导致监听层按完整 `ts_code` 查不到数据的问题，并补充涨跌幅兜底计算。
- 修复 `stock_daily`、`daily_basic` 与 `index_daily` 自动同步在未真正落库时仍错误写入“已同步”标记的问题，避免节点整天跳过应补数据。
- 修复交割单复盘页只展示第一页数据却缺少翻页入口的问题。
- 修复交割单 K 线买卖点标记不可见或定位不明显的问题，改为轻量圆点加文字标注并落在真实成交价格轴线上。

## [0.1.0] - 2026-05-05

### 新增

- 新增股池管理页面，可查看本地股池概览、池内股票和来源条件。
- 新增股池管理页手动新建股池入口，不再依赖一句话选股页面创建股池。
- 新增自选股与股池的批量加入策略监听能力，可将多只股票一次性加入同一监听策略。
- 新增监听触发事件记录、股池流转日志与第一版自动流转规则配置能力。
- 新增自选股批量移除能力，便于清理观察列表中的多只股票。
- 新增股池删除与池内股票批量移除能力，便于维护股池内容。
- 新增一句话选股模块，支持调用独立 Coze 工作流按自然语言筛股并记录查询结果。
- 新增最小可用股池能力，支持从一句话选股结果中勾选股票并加入本地股池。
- 新增市场晴雨表模块，支持通过独立 Coze 工作流获取市场因子、生成交易建议并按交易日落库。
- 新增市场晴雨表同步脚本与独立前端页面，可展示近一个月的因子变化和历史结论。
- 新增后端开发栈一键启动能力，可通过单条命令同时拉起 `web`、`data_sync`、`inference`、`listener`。
- 新增开发栈三级启动档位：`lite`、`standard`、`full`，方便按场景选择节点组合。
- 新增 Coze 工作流数据源适配器，并接入统一数据源管理器。
- 新增 Coze 单股基础信息、日线、实时行情、财务指标、每日指标与交易日历映射能力。
- 新增基于 Coze 的重点股票同步、全市场补库、能力检查和适配器验证脚本。
- 新增重点股票集合提取逻辑，以及按股票池补齐本地 `stock_daily` 和 `daily_basic` 的同步入口。
- 新增系统状态后端与前端页面，用于展示基础服务、数据源、数据集与功能接口状态。
- 新增数据库完整性、覆盖率和数据源路由可见性诊断能力。
- 新增监听通知 dry-run 能力及相关验证/测试覆盖。
- 新增监听告警预览能力，便于在不发送真实消息时验证通知内容。
- 新增撑压线监听策略，支持按单只股票配置支撑线与压力线的两组点位。
- 新增系统状态接口矩阵展示，可按能力场景对比多数据源状态与默认路由。
- 新增提交规范文档，并约定后续提交前需要更新本变更日志。

### 变更

- 调整侧边菜单分组与排序，将市场晴雨表、一句话选股和股池管理前置到核心工作台。
- 调整核心工作台分组，将自选股与市场监听前置到高频工作入口。
- 调整股池类型配置，股池管理页与一句话选股统一复用固定的股池类型选项。
- 调整一句话选股与市场晴雨表页面留白和表格滚动样式，提升宽表场景的可用性。
- 调整 Coze 工作流配置，补充一句话选股专用工作流 ID。
- 调整 Coze 工作流配置，补充市场晴雨表专用工作流 ID。
- 调整提交规范，后续提交信息统一采用 `type(scope): 中文说明` 格式。
- 调整本地开发启动方式，支持通过统一入口直接启动整套常用后端节点。
- 调整一键启动默认档位为 `full`，便于直接拉起最完整的页面功能依赖。
- 重构 `stock_daily` 与 `daily_basic` 同步流程，支持更安全的增量同步、重点股票同步与多源回退。
- 调整全市场日线补库策略，优先使用按交易日抓取与可用数据源回退，降低限频影响。
- 调整统一数据源默认调度规则，使单股、实时、财务类请求优先走更合适的可用数据源。
- 调整数据源配置项与调度参数过滤逻辑，避免多源调用时因额外参数导致适配器失败。
- 调整监听策略配置界面，支持在策略页按股票维护撑压线点位，并自动补全默认高低点价格。
- 重构系统状态页，改为概览加分区加载、缓存和接口矩阵展示。
- 调整系统状态后端接口，拆分为概览与分区请求，降低首屏阻塞时间。
- 调整订阅、监听与股票详情相关链路，使其与当前监听架构保持一致。
- 调整订阅默认参数与初始化脚本，使其与当前监听策略字段定义保持一致。
- 调整 Mongo 连接初始化超时配置，减少本地或受限环境下的长时间阻塞。

- 修复股池工作台缺少删除入口的问题，补齐整池删除与池内股票删除链路。
- 修复自选股列表只能逐只移除的问题，补齐勾选后的批量删除操作。
- 修复市场晴雨表接口直接返回 Mongo 原始文档时导致的 `500` 序列化错误。
- 修复市场晴雨表历史同步串行执行导致的超时问题，改为并发拉取并保留跳过逻辑。
- 修复一句话选股结果结构与当前项目不一致的问题，统一补充 `code / ts_code / market` 元信息。
- 修复分析模块包级导入会阻塞新脚本与新接口的问题，改为惰性导出。
- 修复因本地 `stock_basic` 缺失导致的股票搜索异常。
- 修复多处 Tushare 集成问题，包括错误地址、健康检查与权限不足时的回退逻辑。
- 修复 AKShare 与 BaoStock 在最近交易日推断上的兼容问题。
- 修复统一数据源在单股与交易日相关请求上的默认路由与回退行为。
- 修复重点股票同步与全市场补库脚本的断点续跑、数据覆盖和完整性检查问题。
- 修复监听模块在策略参数、快照处理与通知链路上的兼容问题。
- 修复撑压线策略百分比阈值被误判为倍数的问题，避免远离线位时出现误报。
- 修复股票详情页在订阅记录缺失时无法正常补齐监听入口的问题。
- 修复前端构建阻塞项以及系统状态页若干展示问题。
- 修复报告页面类型检查与无用变量问题，避免能力状态页构建时被无关错误阻塞。
