# Strategy V2 页面原型与交互流

## 1. 文档目的

本文档定义 `Strategy V2` 的前端页面结构与主要交互路径。

目标：

- 新系统单独建立 V2 页面
- 旧页面先保留
- 尽量复用现有股池页、交割单页和部分工作台能力

## 2. 页面边界

### 2.1 继续保留的现有页面

- 旧市场监听页
- 旧股池页
- 旧交割单分析页
- 旧回测入口

### 2.2 新增的 V2 页面

建议新增以下页面：

- `策略中心 V2`
- `场景任务中心 V2`
- `任务详情页 V2`
- `运行结果页 / 运行明细抽屉 V2`

## 3. 页面一：策略中心 V2

### 3.1 页面目标

统一展示“策略定义”，不再把它和“监听订阅任务”混在一起。

### 3.2 页面功能

- 查看内置策略列表
- 查看策略说明
- 查看策略支持的场景
- 查看参数定义
- 查看是否支持跨日状态
- 手动试运行策略
- 从策略直接创建场景任务

### 3.3 页面结构草图

#### 左侧

- 策略分类
- 搜索框
- 策略列表

#### 右侧

- 策略基本信息
- 参数说明
- 支持场景
- 输入示例
- 输出示例
- 试运行面板
- “创建任务”按钮

### 3.4 用户动作

- 选择一个策略
- 查看策略定义
- 填写试运行参数
- 查看策略输出
- 点击“创建任务”

## 4. 页面二：场景任务中心 V2

### 4.1 页面目标

这是 V2 的主工作台。

用户实际使用的核心，不是“策略定义”，而是“使用某策略创建的任务”。

### 4.2 页面标签

建议四个主标签：

- 选股任务
- 监听任务
- 回测任务
- 模拟交易任务

### 4.3 列表字段建议

通用字段：

- 任务名称
- 场景类型
- 策略名称
- 目标范围
- 状态
- 调度方式
- 最近运行时间
- 最近运行结果摘要
- 操作入口

### 4.4 操作入口

- 新建任务
- 编辑任务
- 手动运行
- 启用/暂停任务
- 查看详情
- 查看最近运行

### 4.5 新建任务向导

建议使用分步创建：

1. 选择场景
2. 选择策略
3. 配置目标范围
4. 配置参数
5. 配置动作
6. 配置调度
7. 确认保存

## 5. 页面三：任务详情页 V2

### 5.1 页面目标

查看某一个任务的完整定义和运行历史。

### 5.2 页面区块

- 任务基本信息
- 策略信息
- 目标范围
- 参数配置
- 动作配置
- 调度配置
- 最近运行记录
- 最近触发信号
- 失败日志

### 5.3 不同任务的重点内容

#### 选股任务详情

- 最近一次候选结果
- 候选结果加入股池入口
- 历史运行对比

#### 监听任务详情

- 最近触发记录
- 通知发送情况
- 股池流转结果
- 冷却与频率控制命中情况

#### 回测任务详情

- 回测区间
- 交易配置
- 运行摘要
- 交割单入口

#### 模拟交易任务详情

- 当前状态
- 最近更新
- 当前持仓摘要
- 结果分析入口

## 6. 页面四：运行结果页 V2

### 6.1 页面目标

承接一次具体运行的结果，避免所有信息都堆在任务详情页。

### 6.2 页面信息

- 本次运行概览
- 触发数量
- 信号分布
- 明细表
- 动作执行结果
- 错误与跳过原因

### 6.3 明细表字段建议

- 标的
- 当前信号
- 强度
- 原因
- 标签
- 动作结果
- 是否写入状态

## 7. 关键交互流

### 7.1 日内选股流

目标：

通过 V2 选股任务生成候选，进入现有股池。

步骤：

1. 用户进入策略中心 V2
2. 选择某个策略
3. 点击“创建选股任务”
4. 选择目标范围为全市场或指定股池
5. 设置参数并保存
6. 手动运行
7. 打开运行结果页
8. 勾选候选并加入现有股池

### 7.2 监听流

目标：

通过 V2 监听任务替代旧订阅式监听。

步骤：

1. 用户进入场景任务中心 V2
2. 创建监听任务
3. 选择目标范围
4. 选择动作
5. 配置频率与调度
6. 启用任务
7. 在任务详情页查看触发记录
8. 在现有股池页查看流转结果

### 7.3 回测流

目标：

通过 V2 回测任务统一策略运行与交割单分析入口。

步骤：

1. 用户创建回测任务
2. 选择策略、标的范围、回测区间
3. 配置交易参数
4. 运行回测
5. 生成运行记录
6. 关联交割单分组
7. 跳转现有交割单分析页查看结果

### 7.4 模拟交易流

目标：

按每日实盘数据持续推进模拟交易。

步骤：

1. 用户创建模拟交易任务
2. 配置策略与目标范围
3. 配置调度
4. 任务每日运行
5. 更新持仓与交易数据
6. 用户在任务详情页查看最新状态
7. 需要时进入现有交割单分析页复盘

## 8. 与现有页面的关系

### 8.1 策略中心 V2 与旧市场监听页

旧页继续保留，负责旧链路。

新页负责：

- 新策略定义
- 新任务创建
- 新结果查看

### 8.2 场景任务中心 V2 与旧回测页

旧回测页暂时保留。

V2 建议先新建独立入口，不直接改旧页面，以降低并行开发风险。

### 8.3 V2 与股池页

股池页继续承担：

- 股票容器
- 复盘入口
- 流转结果展示

V2 不重做股池主页面。

### 8.4 V2 与交割单页

交割单页继续承担：

- 回测结果分析
- 模拟交易结果分析

V2 只负责把结果正确送过去。

## 9. 页面路由建议

建议新增独立 V2 路由，避免污染旧页面语义：

- `/strategies-v2`
- `/strategy-tasks`
- `/strategy-tasks/:taskId`
- `/strategy-runs/:runId`

说明：

- 旧 `/strategies` 保持现状
- V2 页面成熟后，再考虑替换菜单入口

## 10. 第一阶段页面实现顺序

建议顺序：

1. 场景任务中心 V2
2. 任务详情页 V2
3. 运行结果页 V2
4. 策略中心 V2

原因：

- 任务中心是业务主入口
- 策略中心更多偏定义和说明，优先级略低于任务操作链路
