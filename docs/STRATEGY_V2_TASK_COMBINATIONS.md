# Strategy V2 任务组合清单

## 1. 组合口径

本文档统计“场景类型 × 目标范围 × 调度方式”的有效组合，并说明每类组合适合做什么。

V1 不把动作组合计入总数，因为动作可以按策略返回值配置多条规则，组合数量会快速膨胀。动作应按条件校验：

- 通知：仅监听。
- 加入股池：仅股票范围。
- 股池流转：仅股池分组。
- 临时清单：仅一次性运行。
- 模拟成交：回测和模拟。

## 2. 有效组合总数

按当前规则：

- 场景目标组合：12 个。
- 调度组合：127 个。

计算方式：

- 选股：4 个目标范围 × 12 个调度 = 48。
- 监听：6 个目标范围 × 11 个调度 = 66。
- 回测：1 个目标范围 × 2 个调度 = 2。
- 模拟：1 个目标范围 × 11 个调度 = 11。

调度数量口径：

- 选股：一次性运行 + 10 个定时选项 + 手动运行 = 12。
- 监听：10 个定时选项 + 手动运行 = 11。
- 回测：一次性运行 + 手动运行 = 2。
- 模拟：10 个定时选项 + 手动运行 = 11。

## 4. 组合功能用途

### 4.1 选股组合

选股的主链路是“筛选候选 -> 进入股池或临时清单 -> 人工或半自动复盘”。

有效目标范围：

- 自选股：适合低成本试策略。
- 持仓股/交易账户：适合从持仓里找加仓、减仓、观察标的。
- 股池分组：适合候选池内二次确认。
- 全市场排除 ST：适合盘中或盘后发现新候选。

有效调度：

- 一次性运行：适合临时筛选，通常配临时清单。
- 定时运行：适合固定时间沉淀候选。
- 手动运行：适合调参和策略验证。

### 4.2 监听组合

监听的主链路是“持续观察目标 -> 信号触发 -> 通知或动作”。

有效目标范围：

- 自选股：个股异动提醒。
- 持仓股/交易账户：持仓盈亏、止盈止损提醒。
- 股池分组：候选池和观察池流转。
- 全市场排除 ST：市场级异动提醒，后端需要限制频率。
- 自定义股票列表：旧监听列表迁移入口。
- 指数：市场情绪和指数条件监听。

有效调度：

- 定时运行：监听主路径。
- 手动运行：调试任务或临时检查。

### 4.3 回测组合

回测的主链路是“选历史区间 -> 选择或创建交割单账户 -> 执行策略 -> 一次性生成最终交割单数据 -> 分析结果”。

有效目标范围：

- 全市场排除 ST。

有效调度：

- 一次性运行：常规回测。
- 手动运行：调参后反复执行。

注意：

- 回测可以使用模拟成交动作，但语义是一次性生成最终交割单数据，而不是每日持续更新。

### 4.4 模拟组合

模拟的主链路是“绑定交易账户 -> 按实盘数据更新 -> 写入模拟成交/持仓结果”。

有效目标范围：

- 全市场排除 ST，并必须绑定某个交割单分组作为模拟交易账户。

有效调度：

- 定时运行：主路径，通常盘后运行。
- 手动运行：调试或补运行。

典型动作：

- 模拟成交。

## 6. 前端联动要求

- 场景类型下拉展示全部场景，策略不支持的场景置灰。
- 目标范围下拉展示全部范围，不符合当前场景的置灰。
- 调度方式下拉展示全部调度，不符合当前场景的置灰。
- 动作类型下拉展示全部动作，不符合当前上下文的置灰。
- 目标范围不显示场景前缀，因为场景类型已经单独选择。
- 置灰项使用灰色字体，辅助说明写明不可选原因。

## 7. 后端校验要求

后端创建任务时必须校验：

- 当前策略是否支持所选场景。
- 场景是否支持所选目标范围。
- 场景是否支持所选调度方式。
- 动作是否满足场景、目标范围和调度条件。
- 事件范围不可创建。
- 模拟任务必须绑定交易账户。
- 回测任务也必须绑定或创建交割单账户。
- 全市场排除 ST 的选股/回测默认补最近三个月时间段。
